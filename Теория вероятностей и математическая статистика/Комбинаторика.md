# Выборки без возвращения (повторений)

Пусть имеется множество X из m элементов. Из множества надо выбрать разные выборки из n элементов, 0 < n < m

1. Размещение $A_{m}^{n}$ - порядок важен
$$A_{m}^{n} = m(m-1)\dots(m - n + 1) = \frac{m!}{(m - n)!}$$
2. Перестановки $P_{m}$ - выбираем все, порядок важен
$$P_{n} = m!$$
3. Сочетания $C_{m}^{n}$ - порядок не важен
$$C_{m}^{n} = \frac{m!}{n!(m - n)!}$$

Пример:
Выбрано 9 человек, надо выбрать секретаря, заместителя, и еще кого-то там
9 * 8 * 7

7 девушек и 10 юношей танцуют

# Выборки с возвращением (повторением)

1. Размещение 
$$m^n$$
2. Перестановки 
$$\frac{т!}{n_{1}! \dots n_{k}!}$$
3. Сочетания $C_{m + n - 1}^{n}$


Примеры:
4 студента сдают экзамен, никто не получил 2, сколько способов распределить оценки: 3^4

б) 8 открыток

в) $C_{10}^8$
